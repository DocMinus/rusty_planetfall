# stories/

Put compiled story files here (`.z3`, `.dat`, ... — not ZIL source). Running
`rustyz` (or `cargo run`) without a file argument opens the first story file
in this folder, alphabetically. Files are recognised by their header, so odd
names such as Planetfall's `planetfall.zip` work too.

Story files are git-ignored; only this README is tracked.

Exception: the planetfall z3 file for this repo's purpose.
It was retrieved from the public repo [https://github.com/the-infocom-files/planetfall](https://github.com/the-infocom-files/planetfall), respectively [https://github.com/historicalsource/planetfall-gold](https://github.com/historicalsource/planetfall-gold).
